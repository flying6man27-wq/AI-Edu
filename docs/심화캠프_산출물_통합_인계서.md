## 1. 왜 로컬에서 해야 하는가

Cowork(클라우드 세션)에서 아웃룩 접근을 시도했고 **두 가지가 독립적으로** 막혀 있음을 실측으로 확인했다.

**① 네트워크 정책 — 마이크로소프트 메일 호스트 차단**

```
outlook.cloud.microsoft     CONNECT tunnel failed, 403
outlook.office.com          CONNECT tunnel failed, 403
graph.microsoft.com         CONNECT tunnel failed, 403
login.microsoftonline.com   302  (로그인 페이지만 열림)
```

크로미움도 동일 지점에서 `ERR_TUNNEL_CONNECTION_FAILED`. 프록시 로그에 거부 기록 확인:

```json
{ "kind": "connect_rejected",
  "detail": "gateway answered 403 to CONNECT (policy denial)",
  "host": "outlook.cloud.microsoft:443" }
```

**② 로그인 세션 없음** — Cowork 컨테이너는 세션마다 새로 만들어지는 빈 샌드박스라 브라우저 프로필·쿠키·MS 로그인 상태가 없다.

이는 `Claude_Code_로컬전환_가이드.md`에 기록된 Firestore 차단과 **같은 성격의 문제**이며, 해법도 같다 —
**Cowork에서 코드를 만들고, 로컬 Claude Code에서 실행한다.**

추가로 스크린샷의 대상 대시보드는 `C:\SECO_HR\26년 인사팀장\2. DX .../index.html` 로컬 경로에 있어
클라우드에서는 애초에 접근이 불가능하다.

## 2. 준비된 것

| 파일 | 내용 |
|---|---|
| `scripts/camp_deliverables.py` | 짚파일 해제 → 제출자 귀속 → 산출물 종합 HTML 생성 (표준 라이브러리만, pip 불필요) |
| `data/심화캠프_대상자_23명.json` | 캠프 대상 23명 명부(성명·회사·이메일). 드라이브 `_DX과제_신청현황`에서 추출 |

### 스크립트 핵심 기능

- **한글 파일명 복원** — 한국 윈도우 압축 프로그램은 UTF-8 플래그 없이 cp949로 파일명을 기록해
  Python이 cp437로 잘못 읽어 `╗≤└╧╜─╟░...`처럼 깨진다. cp437 → cp949 역변환으로 복원한다.
  중첩 폴더 경로까지 복원 검증 완료.
- **제출자 귀속** — zip 파일명뿐 아니라 **내부 경로**에서도 성명을 찾는다.
- **동명이인 처리** — 김현우(상일식품)·김현우(쌤앤파커스)를 회사 힌트(`상일`/`smpk` 등)로 분리.
  판별 불가 시 임의 배정하지 않고 "귀속 미확인"으로 분리해 수동 확인을 요구한다.
- **zip slip 방지** — 압축 경로가 대상 폴더를 벗어나면 건너뛴다.
- **SECO 문서 표준** — 핑크 액센트 헤더, 문서번호 `HR-2026-DX-교육-11`,
  한글 `word-break:keep-all`, A4 인쇄 안전 레이아웃(표·카드 페이지 끊김 방지, 머리행 반복) 적용.

### 검증 결과

실제 cp949 zip 픽스처 6종으로 테스트 완료:

```
제출자 5명 / 대상 23명, 총 파일 9건
귀속 미확인 1건 (성명 없는 파일 — 의도된 동작)

복원 예: ./김현우_상일식품_DX과제산출물/상일식품 분석관리시스템 구축성과 및 발전계획.docx
        ./DX과제_제출/한기성/인베스터유나이티드 투자심사 자동화.xlsx
동명이인: 김현우→상일식품, 김현우→쌤앤파커스 정상 분리
```

## 3. 로컬 실행 절차

### 3-1. 저장소 받기

```powershell
cd "C:\SECO_HR\26년 인사팀장\인사프로그램\People Hub"
git fetch origin claude/advanced-camp-deliverables-integration-1u78le
git checkout claude/advanced-camp-deliverables-integration-1u78le
```

### 3-2. 아웃룩에서 산출물 내려받기

아웃룩에서 심화캠프 DX과제 회신 메일의 첨부를 **폴더 하나에** 모두 저장한다.
짚파일은 풀지 말고 그대로 둔다(스크립트가 처리).

```
C:\SECO_HR\...\심화캠프_산출물\
    김현우_상일식품_....zip
    한기성_....zip
    ...
```

### 3-3. 실행

```powershell
python scripts\camp_deliverables.py --input "C:\SECO_HR\...\심화캠프_산출물"
```

생성물:

```
심화캠프_산출물\산출물_종합.html   ← 산출물 종합 문서
심화캠프_산출물\_해제\             ← 한글명 복원된 원본 파일들
```

옵션: `--output`(HTML 경로), `--extract-dir`(해제 위치), `--docno`(문서번호).

### 3-4. 귀속 미확인 처리

HTML 하단 "귀속 미확인 산출물"에 뜬 항목은 파일명에 성명이 없는 경우다.
해당 zip 파일명 앞에 `성명_회사_`를 붙여 이름을 바꾸고 재실행하면 자동 귀속된다.

## 4. 로컬 Claude Code에 넘길 프롬프트

3-3까지 마친 뒤, 로컬 Claude Code 세션에 아래를 그대로 붙여넣으면 대시보드 반영까지 이어진다.

```
심화캠프 DX과제 산출물을 통합 대시보드에 반영해줘.

1. scripts/camp_deliverables.py 를 실행해 산출물_종합.html 을 생성했다.
   생성된 HTML과 _해제 폴더의 실제 산출물 내용을 읽어라.

2. 각 제출자의 산출물을 실제로 열어보고 아래를 정리해라.
   - DX 과제명
   - 구축 성과 (무엇을 만들었고 무엇이 개선됐는지)
   - 향후 발전계획
   산출물에 없는 내용은 지어내지 말고 "미기재"로 둔다.

3. C:\SECO_HR\26년 인사팀장\2. DX ...\index.html 의 오프라인교육 탭에서
   "교육 결과·산출물"(HR-2026-DX-교육-10) 카드의 아래 값을 실제 수치로 갱신해라.
   - 산출물 제출 n/16
   - 제출된 산출물 목록 (현재 김현우 1건만 하드코딩되어 있음)
   - "나머지 N명은 제출 대기 중" 문구
   기존 카드 마크업 구조와 클래스를 그대로 따르고 새 디자인을 만들지 마라.

4. 산출물_종합.html 을 대시보드에서 "열기 →" 링크로 연결해라.

세부 배경은 docs/심화캠프_산출물_통합_인계서.md 참조.
```

## 5. 남은 확인 사항

- **`온보딩_진도.json`** — 리포지토리·구글 드라이브 어디에서도 찾지 못했다(JSON 전체 목록 검색 확인).
  로컬 `C:\SECO_HR\` 아래에 있을 가능성이 높다. 로컬 세션에서 경로를 확인할 것.
- **회신 현황 최신화** — 드라이브 `_DX과제_신청현황` 시트는 2026-08-04 기준으로 전원 `회신대기`
  상태다. 대시보드는 16명 회신 완료를 표시하므로 시트가 실제보다 뒤처져 있다.
  아웃룩 회신 메일을 기준으로 시트도 함께 갱신할 것.
- **문서번호** — 산출물 종합 문서에 `HR-2026-DX-교육-11`을 부여했다.
  기존 교육 분류 연번(07 교육계획, 08 과제선정, 10 결과보고서) 다음 번호다.
  09번 사용 여부를 대장에서 확인할 것.
