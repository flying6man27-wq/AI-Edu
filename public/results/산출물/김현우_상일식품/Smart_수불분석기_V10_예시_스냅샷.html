화면의 구분은 완제품·분태류 대신 비스킷, 분태, 팝콘·크리스피롤로 표시합니다. 내부 KG/BOX 환산 기준은 기존대로 유지합니다.
품목 상세조회는 전체, 비스킷, 분태, 팝콘·크리스피롤, 기타 분류로 나눠 조회할 수 있습니다.
단위 표시는 일반 완제품 BOX, 분태 KG, 예외 품목코드 112055·112056은 BOX로 표시합니다.
품목 상세조회는 생산·반품·납품·샘플·총출고 중 변동이 있는 품목과 변동월만 표시합니다. 수불 시트 7~79행은 비스킷 라인, 112 계열은 분태류 라인, 130~144행은 팝콘·크리스피롤 라인입니다.
완제품은 수불 수량을 BOX로 그대로 사용합니다. 제품코드 112055와 112056은 BOX 예외 품목으로 지정하여 환산하지 않습니다. 그 외 분태는 제품코드 112로 시작하는 품목으로 분류하고, 수불 시트의 규격을 직접 해석하여 BOX당 총중량을 계산합니다. 예: 10Kg*1봉 = 10Kg, 6Kg*2봉 = 12Kg. 환산 BOX = KG ÷ 규격 총중량(Kg)입니다.
총 납품 = 상일납품 + 미찌납품 + 세코납품, 총 샘플 = 상일샘플 + 미찌샘플, 총 출고 = 총 납품 + 총 샘플입니다. 제품코드가 114로 시작하거나 품목명이 선물세트로 시작하는 품목은 분석 대상에서 완전히 제외합니다. 따라서 품목 수, 생산, 납품, 샘플, 총출고, 재고, 월별 요약, 재고 검증 및 엑셀 저장 결과에 포함되지 않습니다. 월별 재고 검증은 생산입고 시트 E열을 해당 월의 전월재고로 읽고, 직전월 수불 시트 W열 총재고와 비교합니다. 또한 전월재고 + 생산 + 반품 - 총출고 = 당월 총재고 여부를 함께 검증합니다.
